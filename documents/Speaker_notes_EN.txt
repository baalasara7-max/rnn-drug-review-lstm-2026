SLIDE 1
Today we compare three recurrent architectures on the same drug review sentiment task. We implement every recurrent cell manually with PyTorch Linear layers. Our goal is to understand whether changing memory control improves sentiment recognition under a shared experimental protocol. We use rating-derived labels and report the limits of that supervision. The presentation covers the dataset, preprocessing, model design, controlled experiments and measured held-out results. Source: Guidelines_RNN_2627.pdf and resultats/synthese.json.

SLIDE 2
The model receives only the patient review text. It predicts negative, neutral or positive sentiment. We create these labels from the associated rating: one through four is negative, five or six neutral, and seven through ten positive. This is a modeling choice rather than a linguistic annotation. The rating defines the training target but never enters the model as an input. All three architectures solve exactly this same task. Source: course brief and etape_02_categories.py.

SLIDE 3
The downloaded training file contains 161,297 reviews and the raw test file 53,766. About two thirds of the raw training reviews fall in the positive category, while fewer than nine percent are neutral. This imbalance motivates class weights during optimization and macro-F1 during selection. We report accuracy as a complementary metric. The TSV files came from the cited GitHub mirror because the UCI page was inaccessible. We record hashes rather than claiming a fresh byte-level verification against UCI. Sources: dataset TSVs and resultats/synthese.json.

SLIDE 4
We decode HTML, lowercase the text and normalize whitespace while preserving punctuation. We remove repeated normalized texts and rows with contradictory sentiment labels. This leaves 112,285 unique training texts. We split that pool 85/15 with stratification. To keep manual recurrent training feasible on CPU, all experiments use fixed subsets of 12,000 training reviews and 2,000 validation reviews. We clean test data separately and remove overlap against the entire cleaned training and validation pool before selecting 4,000 test reviews. Sources: stages 3, 4 and 10.

SLIDE 5
The embedding represents each token with 64 learned values. The LSTM reads these vectors in order. The cell state c preserves a selectively updated memory. The hidden state h exposes information from that memory and helps calculate the next gates. Both can contain context from multiple preceding tokens. Forget and input gates update c. The output gate controls h. At the last useful token, a linear classifier maps h to three logits. Padding leaves both states unchanged. Sources: etape_07_modele_vanilla.py and the appendix.

SLIDE 6
Vanilla has independent input, forget and output gates. CIFG replaces the learned input gate with one minus the forget gate. This removes one set of learned transforms and imposes a trade-off between retaining memory and accepting new content. WMC adds tanh-transformed memory connections to the gates. Its output gate consults the newly updated cell state, following the exact ordering in the appendix. We use Linear layers and elementwise operations instead of built-in LSTM cells. Counts include embeddings and the classifier. Source: etape_09_variantes.py.

SLIDE 7
We use Adam and weighted cross entropy. Class weights come only from the training subset. Gradient clipping limits the gradient norm to one. Each setting runs four epochs with seed 42. We fit the 12,000-entry vocabulary on the larger training pool only, with no validation or test text. Every sequence keeps at most 128 tokens. The model checkpoints compete using validation macro-F1. A single seed and restricted data budget limit the stability of architecture comparisons. Sources: stage 10 and experiment logs.

SLIDE 8
The table reports the best validation macro-F1 reached by each setting over four epochs. We select an epoch within each run, then select one configuration per architecture. The primary model is the one with the strongest validation result. The comparison changes learning rate and batch size relative to a common baseline, but it does not form a complete factorial grid. Test scores play no role in selection. Results come from the saved experiment JSON files and synthese.json.

SLIDE 9
After selecting the configuration and checkpoint of each architecture, we evaluate the three models on the same cleaned test subset. We also include a classifier that always predicts the majority class. Macro-F1 gives equal importance to all categories and exposes failures on minority classes that accuracy can hide. These are measured scores for a single split and seed. They do not prove universal superiority. The following slide examines the errors of the validation-selected primary model. Source: resultats/synthese.json.

SLIDE 10
Rows of this confusion matrix are actual categories and columns are predicted categories. The diagonal counts correct predictions. Off-diagonal entries show where the model confuses classes. The neutral category has fewer training examples and often represents mixed or ambiguous sentiment, although the matrix alone cannot establish the cause of every error. Saved predictions permit detailed inspection after model selection. Increasing sequence length or changing supervision are possible future experiments rather than conclusions proven by this matrix. Source: predictions and synthese.json.

SLIDE 11
The evidence is limited to one seed, one vocabulary and a restricted optimization subset. Exact deduplication removes identical normalized text but cannot guarantee independence of near-duplicates or reviews about the same medicine. Ratings provide imperfect sentiment labels, and 128-token truncation discards context. Future work should repeat seeds, expand the training budget and investigate neutral or mixed reviews. Pretrained embeddings and splits grouped by drug could test different generalization questions. Any new decisions require validation and a fresh held-out evaluation. Source: experimental protocol and audit.

We implemented all three requested recurrent architectures manually and compared them under the same protocol. CIFG produced the strongest validation configuration.
